# Internacionalização

O app usa duas camadas complementares:

1. `flutter_localizations` fornece textos nativos do Material e Cupertino.
2. `AppLocalizations` (`lib/core/i18n/app_localizations.dart`) concentra os textos
   do produto em PT-BR e inglês.

O idioma escolhido no login é salvo em `SharedPreferences` por
`AppLanguageNotifier`, aplicado no `MaterialApp` e restaurado na próxima abertura.
Novas telas devem usar `context.strings` e adicionar as duas traduções no mesmo
commit. Evite `Text` com texto de produto fixo ou condicionais espalhadas.

## Entrada administrativa por build

A entrada “Gestão” não aparece no build público. Para homologação web ou APK interno, habilite explicitamente:

```bash
flutter build apk --dart-define=PARKHERE_ADMIN_ENTRY=true
flutter run -d chrome --dart-define=PARKHERE_ADMIN_ENTRY=true
```

O build público usa `PARKHERE_ADMIN_ENTRY=false` e mantém o acesso administrativo somente pela rota interna `/admin`.
